# LiliaDB Apple SDK (Swift Package)

Official Swift Package for **LiliaDB**, the local-first multimodel embedded database
written in Rust, for iOS, iPadOS, macOS, watchOS, and tvOS.

The package ships:

- **Generated Swift bindings** (`Lilia`) produced by [UniFFI] from the universal
  C-ABI surface of `crates/lilia-ffi`.
- **`Lilia.xcframework`**, a universal static library that bundles every compiled
  Apple slice together with the generated C headers and module map.

[UniFFI]: https://github.com/mozilla/uniffi-rs

---

## 1. Key Features

- **Multimodel, transactional**: Key/Value, JSON documents, Graph, Full-Text
  Search (FTS5), and declarative SQL share a single SQLite ACID database file.
- **Async & blocking APIs**: every operation is exposed both as a Swift `async`
  function and as a `*Sync` blocking variant.
- **Resource profiles**: tuned SQLite cache / WAL / mmap settings for phones and
  tablets (`MOBILE`), wearables and TV hardware (`CONSTRAINED`), or
  server-class hardware (`SERVER`).
- **Encryption at rest**: transparent authenticated AES-256-GCM via a raw 256-bit
  key or a passphrase (PBKDF2-HMAC-SHA256 key derivation).
- **Exact 64-bit versioning**: entries carry `UInt64` versions without IEEE-754
  precision loss.
- **Mobile lifecycle aware**: `prepareForBackground()` flushes the WAL before the
  OS suspends the process; `close(timeoutMs:)` drains in-flight work gracefully.
- **Broad platform support**: iOS 15+, macOS 12+, watchOS 8+, tvOS 15+.
- **Time-series & geofencing**: Gorilla-compressed sensor telemetry, retention
  policies, GPS tracks, and Geopoly geofences through the same FFI surface.

## 3. Installation

In the v0.1 distribution the package is consumed as a **local Swift package**
from a checked-out LiliaDB repository, not from a remote package registry.

### 3.1 Add the package in Xcode

1. **File → Add Package Dependencies… → Add Local…**
2. Select the `packages/apple-spm` directory.
3. Add the `Lilia` library product to your target.

The package resolves its binary target from
`release/apple/Lilia.xcframework`, so that directory must exist. Build it with
the packaging script (section 4) if it is missing or out of date.

### 3.2 Add the package in `Package.swift`

```swift
// swift-tools-version: 5.9
import PackageDescription

let package = Package(
    name: "MyApp",
    platforms: [
        .iOS(.v15),
        .macOS(.v12),
        .watchOS(.v8),
        .tvOS(.v15),
    ],
    dependencies: [
        .package(path: "../liliadb/packages/apple-spm"),
    ],
    targets: [
        .executableTarget(
            name: "MyApp",
            dependencies: [
                .product(name: "Lilia", package: "apple-spm"),
            ]
        ),
    ]
)
```

### 3.3 Import

All generated bindings live in the `Lilia` module:

```swift
import Lilia
```

### 3.4 Remote binary distribution

The packaging script also emits a zipped XCFramework and its checksum:

```
release/apple/Lilia.xcframework.zip
release/apple/Lilia.xcframework.zip.sha256
```

To distribute the package remotely, publish the zip (for example as a GitHub
release asset) and replace the local binary target in `Package.swift`:

```swift
.binaryTarget(
    name: "LiliaFramework",
    url: "https://example.com/Lilia.xcframework.zip",
    checksum: "<contents of Lilia.xcframework.zip.sha256>"
)
```

## 4. Building the Native Library & Bindings

Native artifacts and Swift bindings are (re)generated by the repository's Apple
packaging script.

### 4.1 Prerequisites

```bash
# Install the Rust targets you need (from the repository root)
rustup target add aarch64-apple-darwin x86_64-apple-darwin
rustup target add aarch64-apple-ios aarch64-apple-ios-sim x86_64-apple-ios
rustup target add aarch64-apple-watchos aarch64-apple-watchos-sim
rustup target add aarch64-apple-tvos aarch64-apple-tvos-sim

# Ensure the Xcode command line tools are available
xcode-select --install
```

### 4.2 Run the script

```bash
# From the repository root
./tools/mobile/build-apple.sh
```

The script:

1. Builds the host-side `uniffi-bindgen` CLI and the `lilia-ffi` dylib.
2. Regenerates the Swift bindings and C headers from the current Rust interface,
   and copies them into `packages/apple-spm/Sources/Lilia/Lilia.swift`.
3. Cross-compiles `lilia-ffi` in release mode for every installed Apple target.
4. Groups the slices (macOS universal, iOS device, iOS simulator, watchOS device
   and simulator, tvOS device and simulator) and creates
   `release/apple/Lilia.xcframework` with `xcodebuild -create-xcframework`.
5. Rewrites `packages/apple-spm/Package.swift`.
6. Zips the XCFramework and writes its SHA-256 checksum for remote distribution.

> `Lilia.swift` is generated code: do not edit it by hand. Re-run the script
> after any change to `crates/lilia-ffi` to refresh the bindings and the
> XCFramework.

### 4.3 Supported targets

| Target                       | Slice                |
| ---------------------------- | -------------------- |
| `aarch64-apple-darwin`       | macOS Apple Silicon  |
| `x86_64-apple-darwin`        | macOS Intel          |
| `aarch64-apple-ios`          | iOS device           |
| `aarch64-apple-ios-sim`      | iOS simulator (arm64)|
| `x86_64-apple-ios`           | iOS simulator (x86_64)|
| `aarch64-apple-watchos`      | watchOS device       |
| `aarch64-apple-watchos-sim`  | watchOS simulator    |
| `aarch64-apple-tvos`         | tvOS device          |
| `aarch64-apple-tvos-sim`     | tvOS simulator       |

Only targets that are installed via `rustup` are compiled. The XCFramework
checked into the repository currently contains the macOS slice; run the script
to produce the mobile slices for your toolchain.

### 4.4 Package structure

```
packages/apple-spm/
├── Package.swift                    # Swift Package manifest
├── README.md
└── Sources/Lilia/
    └── Lilia.swift                  # Generated UniFFI Swift bindings
```

The binary target points at `../../release/apple/Lilia.xcframework`, produced by
the packaging script.

## 5. Quick Start

```swift
import Foundation
import Lilia

func bootstrap() throws {
    let path = FileManager.default
        .urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
        .appendingPathComponent("app.lilia")
        .path

    let db = try LiliaDatabase.open(
        path: path,
        profile: .mobile,
        encryptionKey: nil // or a 32-byte Data for AES-256-GCM
    )
    defer { try? db.closeSync(timeoutMs: 5_000) }

    // 1. Key/Value (binary-safe)
    _ = try db.kvSetSync(
        namespace: "sessions",
        key: Data("sess:1".utf8),
        value: Data("tok_abc".utf8),
        expiresAtMs: Int64(Date().timeIntervalSince1970 * 1000) + 3_600_000
    )

    // 2. JSON documents
    _ = try db.jsonPutSync(
        space: "users",
        id: "usr:1",
        valueJson: #"{"name":"Alice","role":"admin"}"#
    )

    // 3. Graph
    try db.graphSetNodeSync(graph: "social", id: "usr:1", kind: "User", metadataJson: #"{"name":"Alice"}"#)
    try db.graphAddEdgeSync(graph: "social", source: "usr:1", target: "usr:2", kind: "FOLLOWS")

    // 4. Full-text search
    try db.ftsIndexSync(
        collection: "articles",
        docId: "art:1",
        content: "LiliaDB delivers local-first multimodel storage."
    )

    // 5. Declarative SQL
    let result = try db.sqlQuerySync(
        sql: "SELECT id FROM lilia_json WHERE space = 'users'",
        paramsJson: nil
    )
    print(result.columns, result.rowsJson)
}
```

### Async variant

```swift
func bootstrapAsync() async throws {
    let db = try LiliaDatabase.open(path: path, profile: .mobile, encryptionKey: nil)

    let version = try await db.kvSet(
        namespace: "sessions",
        key: Data("sess:1".utf8),
        value: Data("tok_abc".utf8),
        expiresAtMs: nil
    )

    let hits = try await db.ftsSearch(collection: "articles", query: "multimodel", limit: 5)
    print(version, hits.map(\.docId))

    try await db.close(timeoutMs: 5_000)
}
```

## 6. Opening a Database

```swift
// Raw 256-bit key (exactly 32 bytes, otherwise a Crypto error is thrown)
let key = Data((0..<32).map { _ in UInt8.random(in: 0...255) })
let db = try LiliaDatabase.open(path: path, profile: .mobile, encryptionKey: key)

// Passphrase with PBKDF2-HMAC-SHA256 key derivation
let db2 = try LiliaDatabase.openWithPassphrase(
    path: path,
    profile: .mobile,
    passphrase: "correct horse battery staple"
)

// Unencrypted
let db3 = try LiliaDatabase.open(path: path, profile: .constrained, encryptionKey: nil)
```

- `path` is the database file path. Prefer `Application Support` (or
  `noBackupFilesDir` equivalents) for data that should not be purged, and exclude
  large databases from iCloud backups when appropriate.
- When a key or passphrase is supplied, transparent authenticated AES-256-GCM
  encryption protects values, vectors, and WAL frames on disk.
- Opening the same path from multiple processes is not supported; a single
  `LiliaDatabase` instance should own the file.

### Resource profiles

| Profile                  | Tuned for                         | Durability | Busy timeout | Writer queue | Read pool | WAL checkpoint | mmap     | Page cache |
| ------------------------ | --------------------------------- | ---------- | ------------ | ------------ | --------- | -------------- | -------- | ---------- |
| `FfiResourceProfile.server`      | Macs and server-class hardware | `durable`  | 5 000 ms     | 64           | 4         | 16 MB / 5 s    | 256 MB   | 64 MB      |
| `FfiResourceProfile.mobile`      | iPhone, iPad, Apple TV         | `balanced` | 5 000 ms     | 32           | 2         | 4 MB / 3 s     | 32 MB    | 8 MB       |
| `FfiResourceProfile.constrained` | Apple Watch, low-memory devices| `balanced` | 3 000 ms     | 16           | 1         | 1 MB / 1.5 s   | disabled | 2 MB       |

## 7. Threading Model

Every operation comes in two flavors:

- **`async` variants** (`kvGet`, `jsonPut`, `ftsSearch`, …): dispatched to the
  Rust async executor through `spawn_blocking`; safe to call from any Swift
  concurrency context.
- **`*Sync` variants** (`kvGetSync`, `jsonPutSync`, `ftsSearchSync`, …): execute
  the FFI call inline on the calling thread. Never call them on the main thread
  for non-trivial work; dispatch to a background queue instead.

```swift
// Async — preferred for UI-driven work
Task {
    let doc = try await db.jsonGet(space: "users", id: "ada")
    await MainActor.run { render(doc) }
}

// Sync — off the main thread
DispatchQueue.global(qos: .userInitiated).async {
    let ok = try? db.quickCheckSync()
    print(ok ?? false)
}
```

`LiliaDatabase` wraps a thread-safe Rust `Arc<Database>`; serialize access at the
call site if your code mutates shared state across tasks.

## 8. Key/Value (`kv*`)

Keys and values are binary `Data`. `kvSet` returns the new `UInt64` version.

```swift
let version: UInt64 = try db.kvSetSync(
    namespace: "sessions",
    key: Data("sess:1".utf8),
    value: Data("tok_abc".utf8),
    expiresAtMs: Int64(Date().timeIntervalSince1970 * 1000) + 3_600_000 // or nil
)

let entry: FfiKvEntry? = try db.kvGetSync(namespace: "sessions", key: Data("sess:1".utf8))
if let entry {
    let text = String(decoding: entry.value, as: UTF8.self)
    print(entry.version, text, entry.expiresAtMs as Any)
}

// Keyset-paginated scan; `after` is an exclusive cursor (pass the last key of
// the previous page), `limit` caps the page size.
var after: Data?
repeat {
    let page: [FfiKvEntry] = try db.kvScanSync(namespace: "sessions", after: after, limit: 100)
    page.forEach { /* ... */ }
    after = page.last?.key
} while !(after == nil)

let deleted: Bool = try db.kvDeleteSync(namespace: "sessions", key: Data("sess:1".utf8))
```

`FfiKvEntry` is
`{ namespace: String, key: Data, value: Data, version: UInt64, expiresAtMs: Int64? }`.

| Method      | Signature                                                                                     |
| ----------- | --------------------------------------------------------------------------------------------- |
| `kvGet`     | `(namespace: String, key: Data) async throws -> FfiKvEntry?`                                  |
| `kvSet`     | `(namespace: String, key: Data, value: Data, expiresAtMs: Int64?) async throws -> UInt64`     |
| `kvDelete`  | `(namespace: String, key: Data) async throws -> Bool`                                         |
| `kvScan`    | `(namespace: String, after: Data?, limit: UInt32) async throws -> [FfiKvEntry]`               |

Each method also has a `*Sync` variant with the same parameters and a `throws`
signature.

## 9. JSON Documents (`json*`)

Documents are passed as JSON strings (`valueJson`); parse them with
`JSONDecoder`, `JSONSerialization`, or any JSON library. `jsonPut` returns the
new `UInt64` version.

```swift
let version: UInt64 = try db.jsonPutSync(
    space: "users",
    id: "usr:1",
    valueJson: #"{"name":"Alice","role":"admin"}"#
)

let doc: FfiJsonEntry? = try db.jsonGetSync(space: "users", id: "usr:1")
if let doc {
    let data = Data(doc.valueJson.utf8)
    let object = try JSONSerialization.jsonObject(with: data)
    print(object, doc.version)
}

let deleted: Bool = try db.jsonDeleteSync(space: "users", id: "usr:1")

// Filtered query: a JSON object of field-equality predicates combined with AND.
// Array fields match when any element equals the value (multikey).
let admins: [FfiJsonEntry] = try db.jsonFindSync(
    space: "users",
    queryJson: #"{"role":"admin"}"#,
    afterId: nil, // exclusive keyset cursor, like kvScan's `after`
    limit: 50
)
```

`FfiJsonEntry` is
`{ space: String, id: String, valueJson: String, version: UInt64 }`.

| Method       | Signature                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| `jsonGet`    | `(space: String, id: String) async throws -> FfiJsonEntry?`                                            |
| `jsonPut`    | `(space: String, id: String, valueJson: String) async throws -> UInt64`                                |
| `jsonDelete` | `(space: String, id: String) async throws -> Bool`                                                     |
| `jsonFind`   | `(space: String, queryJson: String, afterId: String?, limit: UInt32) async throws -> [FfiJsonEntry]`   |

Each method also has a `*Sync` variant.

## 10. Graph (`graph*`)

Directed graphs with typed nodes, typed edges, neighbor traversal, and transitive
reachability.

```swift
try db.graphSetNodeSync(graph: "social", id: "usr:1", kind: "User", metadataJson: #"{"name":"Alice"}"#)
try db.graphSetNodeSync(graph: "social", id: "usr:2", kind: "User", metadataJson: #"{"name":"Bob"}"#)
try db.graphAddEdgeSync(graph: "social", source: "usr:1", target: "usr:2", kind: "FOLLOWS")

let node: FfiGraphNode? = try db.graphGetNodeSync(graph: "social", id: "usr:1")

let neighbors: [String] = try db.graphNeighborsSync(
    graph: "social",
    nodeId: "usr:1",
    direction: .outgoing, // .outgoing | .incoming | .both
    kindFilter: "FOLLOWS" // or nil for all edge kinds
)

// Includes the starting nodes and every reachable node.
let network: [String] = try db.graphReachabilitySync(
    graph: "social",
    startNodes: ["usr:1"],
    direction: .outgoing
)

let removedEdge: Bool = try db.graphRemoveEdgeSync(graph: "social", source: "usr:1", target: "usr:2", kind: "FOLLOWS")
let removedNode: Bool = try db.graphDeleteNodeSync(graph: "social", id: "usr:2")
```

`FfiGraphNode` is
`{ graph: String, id: String, kind: String, metadataJson: String }`.
The record `FfiGraphEdge` (`graph`, `source`, `target`, `kind`) is also part of
the generated bindings.

| Method            | Signature                                                                                                       |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| `graphSetNode`    | `(graph: String, id: String, kind: String, metadataJson: String) async throws`                                  |
| `graphGetNode`    | `(graph: String, id: String) async throws -> FfiGraphNode?`                                                     |
| `graphDeleteNode` | `(graph: String, id: String) async throws -> Bool`                                                              |
| `graphAddEdge`    | `(graph: String, source: String, target: String, kind: String) async throws`                                    |
| `graphRemoveEdge` | `(graph: String, source: String, target: String, kind: String) async throws -> Bool`                            |
| `graphNeighbors`  | `(graph: String, nodeId: String, direction: FfiDirection, kindFilter: String?) async throws -> [String]`        |
| `graphReachability` | `(graph: String, startNodes: [String], direction: FfiDirection) async throws -> [String]`                     |

Each method also has a `*Sync` variant.

## 11. Full-Text Search (`fts*`)

SQLite FTS5 with BM25 ranking and snippet extraction.

```swift
try db.ftsIndexSync(
    collection: "articles",
    docId: "art:1",
    content: "LiliaDB delivers local-first multimodel storage."
)

let hits: [FfiFtsHit] = try db.ftsSearchSync(collection: "articles", query: "multimodel storage", limit: 5)
for hit in hits {
    print("\(hit.docId): rank=\(hit.rank) snippet=\(hit.snippet)")
}

let removed: Bool = try db.ftsDeleteSync(collection: "articles", docId: "art:1")
```

`FfiFtsHit` is `{ collection: String, docId: String, snippet: String, rank: Double }`.

| Method      | Signature                                                                                    |
| ----------- | -------------------------------------------------------------------------------------------- |
| `ftsIndex`  | `(collection: String, docId: String, content: String) async throws`                          |
| `ftsSearch` | `(collection: String, query: String, limit: UInt32) async throws -> [FfiFtsHit]`             |
| `ftsDelete` | `(collection: String, docId: String) async throws -> Bool`                                   |

Each method also has a `*Sync` variant.

## 12. Declarative SQL (`sqlQuery`)

SQLite views over the multimodel storage:

| View                | Columns                                                           |
| ------------------- | ----------------------------------------------------------------- |
| `lilia_json`        | `(space, id, value, version)` — decoded plaintext JSON            |
| `lilia_kv`          | `(namespace, key, value, version, expires_at_ms)` — decoded bytes |
| `lilia_graph_nodes` | `(graph, id, kind, metadata)`                                     |
| `lilia_graph_edges` | `(graph, source, target, kind)`                                   |

Positional parameters are bound by passing a JSON array of values as
`paramsJson` (or `nil` for none):

```swift
let result: FfiSqlQueryResult = try db.sqlQuerySync(
    sql: """
    SELECT id, json_extract(value, '$.name') AS name
    FROM lilia_json
    WHERE space = ?1
    """,
    paramsJson: #"["users"]"#
)

result.columns      // ["id", "name"]
result.rowsJson     // each row serialized as a JSON array, e.g. #"["usr:1","Alice"]"#
result.rowsAffected // 0 for SELECT, mutation count otherwise
```

`FfiSqlQueryResult` is `{ columns: [String], rowsJson: [String], rowsAffected: UInt64 }`.

| Method     | Signature                                                                      |
| ---------- | ------------------------------------------------------------------------------ |
| `sqlQuery` | `(sql: String, paramsJson: String?) async throws -> FfiSqlQueryResult`         |

`sqlQuerySync` provides the blocking variant.

## 13. Time-Series & Geofencing

The universal FFI surface also exposes time-series and geofencing operations.
They are exported by `crates/lilia-ffi`; run `tools/mobile/build-apple.sh` to
regenerate `Lilia.swift` so the bindings below are available.

### Time-series

```swift
let points = [
    FfiTimeSeriesPoint(timestamp: 1_700_000_000_000, value: 72.0),
    FfiTimeSeriesPoint(timestamp: 1_700_000_001_000, value: 72.5),
    FfiTimeSeriesPoint(timestamp: 1_700_000_002_000, value: 73.0),
]

try db.tsAppendPointsSync(seriesId: "watch_hr", points: points)

let range: [FfiTimeSeriesPoint] = try db.tsQueryRangeSync(
    seriesId: "watch_hr",
    startTime: 1_700_000_000_000,
    endTime: 1_700_000_002_000
)

let stats: FfiTimeSeriesStats? = try db.tsQueryStatsSync(
    seriesId: "watch_hr",
    startTime: 1_700_000_000_000,
    endTime: 1_700_000_002_000
)

// Adaptive downsampling to at most `maxPoints` buckets
let downsampled: [FfiTimeSeriesPoint] = try db.tsQueryAutoSync(
    seriesId: "watch_hr",
    startTime: 1_700_000_000_000,
    endTime: 1_700_000_002_000,
    maxPoints: 100
)

// Retention policy with per-resolution aggregation rules
let policy = FfiTimeSeriesLifecyclePolicy(
    seriesPattern: "watch_*",
    rules: [
        FfiTimeSeriesRetentionRule(
            resolutionMs: 1_000,
            retentionMs: 24 * 3_600 * 1_000,
            aggregation: .avg
        ),
        FfiTimeSeriesRetentionRule(
            resolutionMs: 60_000,
            retentionMs: nil,
            aggregation: .avg
        ),
    ]
)
try db.tsSetPolicySync(policy: policy)
let applied: FfiTimeSeriesRetentionStats = try db.tsApplyRetentionSync()

// Standalone Gorilla compression helpers
let compressed: Data = try tsCompressPoints(points: range)
let restored: [FfiTimeSeriesPoint] = try tsDecompressPoints(bytes: compressed)
```

| Method                         | Signature                                                                                             |
| ------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `tsAppendPoints`               | `(seriesId: String, points: [FfiTimeSeriesPoint]) async throws`                                       |
| `tsQueryRange`                 | `(seriesId: String, startTime: Int64, endTime: Int64) async throws -> [FfiTimeSeriesPoint]`           |
| `tsQueryStats`                 | `(seriesId: String, startTime: Int64, endTime: Int64) async throws -> FfiTimeSeriesStats?`            |
| `tsQueryAuto`                  | `(seriesId: String, startTime: Int64, endTime: Int64, maxPoints: UInt32) async throws -> [FfiTimeSeriesPoint]` |
| `tsQueryRangeWithResolution`   | `(seriesId: String, resolutionMs: Int64, startTime: Int64, endTime: Int64) async throws -> [FfiTimeSeriesPoint]` |
| `tsSetPolicy`                  | `(policy: FfiTimeSeriesLifecyclePolicy) async throws`                                                 |
| `tsGetPolicy`                  | `(seriesPattern: String) async throws -> FfiTimeSeriesLifecyclePolicy?`                               |
| `tsListPolicies`               | `() async throws -> [FfiTimeSeriesLifecyclePolicy]`                                                   |
| `tsDeletePolicy`               | `(seriesPattern: String) async throws -> Bool`                                                        |
| `tsApplyRetention`             | `() async throws -> FfiTimeSeriesRetentionStats`                                                      |

Free functions: `tsCompressPoints(points:)`, `tsDecompressPoints(bytes:)`.

`FfiTimeSeriesStats` is `{ min, max, avg, sum: Double, count: UInt64 }`.
`FfiDownsampleAggregation` is `.avg`, `.min`, `.max`, `.sum`, `.first`, `.last`,
`.count`.

### Geofencing & GPS tracks

```swift
// Build a 16-vertex circle polygon (GeoJSON-style string)
let park = geoCreateCirclePolygon(
    centerLon: 2.2945,
    centerLat: 48.8584,
    radiusMeters: 250,
    nVertices: 16
)

try db.geoAddFenceSync(
    id: "workout_zone",
    name: "Park Perimeter",
    category: "running",
    polygonJson: park,
    metadata: nil
)

let inside: Bool = try db.geoContainsPointSync(polygonJson: park, lon: 2.2945, lat: 48.8584)
let matches: [FfiGeofenceMatch] = try db.geoFindFencesForPointSync(lon: 2.2945, lat: 48.8584)

let track = [
    FfiGpsPoint(timestamp: 1_700_000_000_000, latitude: 48.8580, longitude: 2.2940,
                altitude: 35.0, speed: 3.0, accuracy: 5.0),
    FfiGpsPoint(timestamp: 1_700_000_005_000, latitude: 48.8584, longitude: 2.2945,
                altitude: 35.5, speed: 3.1, accuracy: 4.0),
]
let breaches: [FfiGeofenceMatch] = try db.geoRecordGpsPointsSync(trackId: "run_1", points: track)
let stored: [FfiGpsPoint] = try db.geoGetTrackPointsSync(trackId: "run_1", startTime: nil, endTime: nil)
let meters: Double = try db.geoTrackDistanceSync(trackId: "run_1")

// Distance helper (meters, haversine)
let distance = geoHaversineDistance(lat1: 48.8580, lon1: 2.2940, lat2: 48.8584, lon2: 2.2945)
```

| Method                    | Signature                                                                                                            |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `geoAddFence`             | `(id: String, name: String, category: String, polygonJson: String, metadata: String?) async throws`                  |
| `geoRemoveFence`          | `(id: String) async throws -> Bool`                                                                                  |
| `geoContainsPoint`        | `(polygonJson: String, lon: Double, lat: Double) async throws -> Bool`                                               |
| `geoFindFencesForPoint`   | `(lon: Double, lat: Double) async throws -> [FfiGeofenceMatch]`                                                      |
| `geoRecordGpsPoints`      | `(trackId: String, points: [FfiGpsPoint]) async throws -> [FfiGeofenceMatch]`                                        |
| `geoGetTrackPoints`       | `(trackId: String, startTime: Int64?, endTime: Int64?) async throws -> [FfiGpsPoint]`                                |
| `geoTrackDistance`        | `(trackId: String) async throws -> Double`                                                                           |

Free functions: `geoHaversineDistance(lat1:lon1:lat2:lon2:)`,
`geoCreateCirclePolygon(centerLon:centerLat:radiusMeters:nVertices:)`.

`FfiGpsPoint` is
`{ timestamp: Int64, latitude: Double, longitude: Double, altitude: Double?, speed: Double?, accuracy: Double? }`.
`FfiGeofenceMatch` is
`{ id: String, name: String, category: String, metadata: String? }`.

## 14. Maintenance, Backup & Lifecycle

```swift
// SQLite PRAGMA quick_check integrity verification
let ok: Bool = try db.quickCheckSync()

// Explicit WAL checkpoint
try db.checkpointSync()

// Atomic online backup to another file
try db.backupSync(destinationPath: "\(documentsPath)/backup.lilia")

// Graceful close: drain accepted in-flight operations, then release resources.
try db.closeSync(timeoutMs: 5_000) // timeout in milliseconds, as UInt64
```

- `close` drains accepted in-flight operations before releasing resources; the
  timeout bounds the wait in milliseconds.
- Operations started after `close` fail.
- The `async` variants `quickCheck`, `checkpoint`, `backup`, and `close` behave
  identically for Swift concurrency callers.

### App lifecycle integration

`prepareForBackground()` flushes the WAL and commits pending pages before the OS
suspends your process. Call it when your app enters the background:

```swift
#if os(iOS) || os(tvOS)
import UIKit

final class LiliaLifecycleObserver {
    private let db: LiliaDatabase

    init(db: LiliaDatabase) {
        self.db = db
        NotificationCenter.default.addObserver(
            self,
            selector: #selector(didEnterBackground),
            name: UIApplication.didEnterBackgroundNotification,
            object: nil
        )
    }

    @objc private func didEnterBackground() {
        try? db.prepareForBackground()
    }
}
#endif
```

On macOS and watchOS, use the corresponding `NSApplication` / `WKExtension`
lifecycle notifications.

## 15. Error Handling

All operations throw `LiliaFfiError`, an enum with a `String` payload per case:

| Case                          | Meaning                                                              |
| ----------------------------- | -------------------------------------------------------------------- |
| `LiliaFfiError.Storage`       | SQLite / storage engine failure                                      |
| `LiliaFfiError.InvalidInput`  | Malformed JSON, invalid key length, bad arguments                    |
| `LiliaFfiError.NotFound`      | Requested entry does not exist                                       |
| `LiliaFfiError.Conflict`      | Optimistic concurrency or busy conflict                              |
| `LiliaFfiError.Crypto`        | Encryption / decryption failure (e.g. wrong key, invalid key length) |
| `LiliaFfiError.Generic`       | Any other engine error                                               |

```swift
do {
    _ = try db.jsonPutSync(space: "users", id: "usr:1", valueJson: payload)
} catch let LiliaFfiError.InvalidInput(message) {
    print("Malformed JSON payload: \(message)")
} catch let LiliaFfiError.Crypto(message) {
    print("Decryption failed (wrong key?): \(message)")
} catch {
    print("Database error: \(error)")
}
```

`LiliaFfiError` conforms to `LocalizedError`, so `error.localizedDescription`
returns a debug description of the case and payload.
